TargSeek - Analysis Pipeline (Snakefile_analysis)
==================================================

What it does: takes the proteins from the download pipeline, picks a 3D
structure per protein, predicts membrane topology, aligns sequences,
scores conservation (ConSurf), and predicts B-cell epitopes (BepiPred 3.0).

Run the download pipeline FIRST (see USAGE_DOWNLOAD.txt).


1. BEFORE YOU START
-------------------
  conda activate targseek

  External tools (installed separately; set their paths in
  config/config_analysis.yaml):
    ConSurf standalone   consurf:  script_path
    BepiPred 3.0         bepipred: path
    DeepTMHMM            tools/DeepTMHMM (runs via biolib, needs internet)

  Use the same batch and parameter set as the download pipeline:
    species_batches:
      - analysis1
    quickgo_paramsets:
      - params1


2. RUN IT
---------
  Check first (shows what would run, changes nothing):
    snakemake -s Snakefile_analysis all_analysis -n

  Run everything:
    snakemake -s Snakefile_analysis all_analysis --cores 4

  ConSurf and BepiPred are slow (hours). If the run stops, start the same
  command again; finished steps are skipped.


3. STAGES (run one at a time if you want)
-----------------------------------------
  Target                          What it does
  ------------------------------  ---------------------------------------------
  stage1_sequence_preparation     Pick sequences for the MSA, pick the best 3D
                                  structure per protein
  stage2_alignments_topology      DeepTMHMM topology, keep surface proteins,
                                  MAFFT alignments (with and without 3D sequence)
  stage3_conservation_analysis    ConSurf conservation on the 3D structures
  stage4_epitope_predictions      BepiPred epitopes, topology filter, BLAST
                                  cross-reactivity, PyMOL images, final reports

  Example:
    snakemake -s Snakefile_analysis stage1_sequence_preparation --cores 4

  Each stage also runs the stages before it if they are not done yet.

  Other targets:
    all_consurf_analysis                       ConSurf only
    all_integrated_epitope_analysis            integrated epitope reports
    all_comprehensive_epitope_visualizations   extra figures


4. WHERE THE RESULTS GO
-----------------------
  Everything is in results/{analysis}_{paramset}/protein_analysis/

  stage1_sequence_preparation_3d_selection/
      msa_fasta_sequences/gram_{group}/           sequences per gene
      3d_structure_selection_results/             chosen 3D structure per gene
  stage2_multiple_sequence_alignments_topology/
      topology_prediction_results/                DeepTMHMM + surface protein lists
      mafft_alignments/gram_{group}/              alignments
      mafft_alignments_with_3d/gram_{group}/      alignments incl. 3D sequence
  stage3_quality_assessment_conservation_analysis/
      consurf_analysis/gram_{group}/              ConSurf scores
  stage4_epitope_predictions_and_reports/
      epitope_prediction_results/gram_{group}/    BepiPred epitopes + tables
      final_reports/gram_{group}/                 integrated reports

  {group} = positive or negative (Gram stain)


5. SETTINGS (config/config_analysis.yaml)
-----------------------------------------
  mafft.threads                          CPU threads for MAFFT (default 8)
  structure_selection                    how the 3D structure is chosen
                                         (random_seed keeps it reproducible)
  structure_selection.manual_overrides   force a specific structure for a gene
  topology.min_extracellular_aa          min. extracellular residues to count
                                         as a surface protein (default 30)
  bepipred.threshold                     epitope score cut-off, 0-1 (default 0.5)
  bepipred.min_epitope_length            shortest epitope kept (default 6)
  consurf.enabled / bepipred.enabled     switch a tool off (true/false)

  You don't need to edit the Snakefile.


6. COMMON PROBLEMS
------------------
  "Missing input files":  run the download pipeline first for the same
                          batch and parameter set.

  Force one step to run again:
    snakemake -s Snakefile_analysis all_analysis --cores 4 \
        --forcerun mafft_msa_filtered

  ConSurf/BepiPred not found:  check the paths in config/config_analysis.yaml.

  Running out of memory:  use fewer cores, e.g. --cores 2
