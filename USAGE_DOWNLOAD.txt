TargSeek - Download Pipeline (Snakefile_download)
==================================================

What it does: classifies your species by Gram stain, finds candidate genes
from GO terms, checks how many species have each gene, selects proteins,
and downloads their sequences and 3D structures.

Run it BEFORE the analysis pipeline (see USAGE_ANALYSIS.txt).


1. BEFORE YOU START
-------------------
  conda activate targseek

  You need these files:
    config/login/bacdive_info.txt     BacDive login (line 1: email, line 2: password)
    config/login/ncbi_info.txt        NCBI email (+ API key recommended)
    config/species/<batch>.txt        one species name per line
    config/quickgo/<paramset>.json    GO terms / QuickGO search parameters

  Copy the *.example.txt files in config/login/ to get started.

  Choose which batch and parameter set to run in config/config_download.yaml:
    species_batches:
      - analysis1
    quickgo_paramsets:
      - params1


2. RUN IT
---------
  Check first (shows what would run, changes nothing):
    snakemake -s Snakefile_download all_download_data -n

  Run everything:
    snakemake -s Snakefile_download all_download_data --cores 4

  Interrupted? Run the same command again. Finished steps are skipped and
  downloads resume where they stopped.


3. STAGES (run one at a time if you want)
-----------------------------------------
  Target                          What it does
  ------------------------------  ---------------------------------------------
  stage1_species_classification   Gram +/- classification (BacDive),
                                  BLAST reference databases
  stage2_gene_discovery           Genes from GO terms (QuickGO), aliases,
                                  surface-accessible filter
  stage3_protein_selection        Species coverage per gene (NCBI),
                                  final protein selection
  stage4_downloads                Protein sequences, 3D structures (PDB/AlphaFold),
                                  structure metadata, HTML report

  Example:
    snakemake -s Snakefile_download stage1_species_classification --cores 4

  Each stage also runs the stages before it if they are not done yet.


4. WHERE THE RESULTS GO
-----------------------
  {analysis} = species batch (e.g. analysis1), {paramset} = e.g. params1

  Gram classification   data/bacdive/{analysis}/gram_positive.txt
                        data/bacdive/{analysis}/gram_negative.txt
  Candidate genes       data/quickgo/{paramset}/protein_to_be_tested.txt
  Coverage table        results/{analysis}_{paramset}/gene_selection/coverage_count.tsv
  Selected proteins     results/{analysis}_{paramset}/gene_selection/summary.tsv
  Download report       results/{analysis}_{paramset}/gene_selection_report.html
  Protein sequences     data/protein_sequences/
  3D structures         data/protein_structures/pdb_files/
  BLAST databases       data/blast_databases/   (see BLAST_DATABASES.md)


5. SETTINGS (config/config_download.yaml)
-----------------------------------------
  gram_thresholds         minimum % of species that must have a gene
                          (default 50 for both groups)
  protein_selection       how many proteins to keep per group
  blast_databases         which reference proteomes to download (true/false)

  You don't need to edit the Snakefile.


6. COMMON PROBLEMS
------------------
  Force one step to run again:
    snakemake -s Snakefile_download all_download_data --cores 4 \
        --forcerun classify_taxa_by_gram

  Running out of memory:  use fewer cores, e.g. --cores 2

  Hide NumPy/pandas warnings:
    PYTHONWARNINGS="ignore" snakemake -s Snakefile_download all_download_data --cores 4

  The cache/ folder stores API results and takes hours to rebuild.
  Don't delete it.
